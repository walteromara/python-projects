## Projects

### 1. Clinic Patient Manager

A beginner-friendly command-line application for managing basic patient records.

#### Features

- Add a patient
- View recorded patients
- Display patient names and ages
- Interactive command-line menu
- Basic input handling

#### Technologies

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements

#### How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python clinic_patient_manager.py
